# ScaleUpSocial - Social Media Management & Content Creation Agency

High converting, premium website for **ScaleUpSocial**, a premier social media management and content creation agency in India.

## Features
- **Astro 5 Static Architecture**: Lightning-fast performance, zero client-side bloat.
- **WebGL Interactive Background**: Custom GPU-accelerated scanning animation.
- **Creator Network Showcase**: Verified creator profiles and work proof.
- **RAG AI Assistant**: Interactive AI assistant (Jenny) trained on all services, pricing, and FAQs.
- **Calendly & WhatsApp Integration**: Direct booking and instant consultation funnels.
- **Responsive & Premium Aesthetics**: Tailored typography, sleek dark mode aesthetics, and micro-interactions.

## Getting Started

### Prerequisites
- Node.js 18+
- npm or yarn

### Installation
```bash
npm install
```

### Running Locally
```bash
npm run dev
```
Open [http://localhost:3000](http://localhost:3000) in your browser.

### Building for Production
```bash
npm run build
```
The output will be built to the `dist/` directory.
